隐私概览

MNN Chat 的普通对话在设备上完成，聊天记录保存在本机。模型下载、Agent 搜索和网页读取会联网。

当前版本免费，无需注册账户，没有广告追踪，也未接入自动使用统计或崩溃上传服务。系统诊断、备份和分享功能遵循各自的设置。

本地对话

您输入的文字、模型回答，以及您提供且模型支持的图片、音视频和文件，用于本机推理、显示和保存对话。部分媒体会生成临时文件。较早的消息可能由本地模型整理为摘要，并随聊天保存。

本地对话不会把输入发给云端大模型来生成回答，我们也不会通过这项功能获取您的聊天用于训练。模型、语言和推理设置保存在本机；可用空间、运行错误及性能信息用于下载检查和故障处理。

模型目录与下载

打开或刷新模型目录时，App 会请求在线列表，即使您还没有开始下载。下载模型时，会向所选平台发送模型标识和文件路径，通常不需要聊天正文。

目录、下载平台和它们的分发服务可以接收 IP 地址、请求时间、请求头等网络信息。当前使用的服务及链接列在“联网服务说明”中。

Agent 搜索与网页读取

Agent 会把搜索词发给搜索服务，并读取所选网页。搜索词可能包含整段问题，也可能来自聊天上下文或长期记忆。 模型未给出有效搜索词时，App 可能直接使用您的问题；结果不足时，同一搜索词可能发给多个搜索服务。

搜索服务会接收搜索词和连接信息；目标网站会接收网址的路径、查询参数和连接信息。请避免在其中放入身份证件、健康或财务信息、他人隐私，以及带访问凭据的网址。

这些服务可能保存请求记录，部分平台或网站使用境外服务器，具体地点和保存期限取决于服务方。查看政策或开启 Agent 不等于同意所有数据处理；涉及依法需要单独告知、同意或办理手续的事项，仍需另行完成。

Agent 记忆

Agent 可以把偏好、事实和可复用的做法保存在本机，供后续 Agent 对话使用。保存可能由模型发起，也可能来自您明确提出的记忆请求。这些内容还可能被用于生成搜索词。

聊天与记忆分开保存。 删除聊天不会清除记忆；清除记忆也不会删除原始聊天。可在“设置 → Agent 记忆与技能”查看和清除。当前对话可能仍保留已加载的内容，清除后请停止生成并新建对话。

Agent 模式按对话选择。若不想继续使用，请停止生成并新建未开启 Agent 的普通对话；这不会关闭模型目录和下载的网络请求。

权限与分享

相机用于拍摄输入，照片权限用于选择或保存媒体，麦克风用于录音。您可以在 iOS 设置中调整授权；不使用这些功能，仍可进行文字对话。文件功能只访问您选择的文件。

复制消息会将内容写入系统剪贴板。保存或分享的内容会交给您选择的照片、文件、邮件或其他应用处理。操作前请确认内容和接收对象。

保存与删除

聊天、附件、摘要、模型、设置和长期记忆保存在 App 的本地数据区。聊天与记忆通常保留到您删除、清除或更新替换，关闭 App 不会自动删除。下载和运行过程还会产生临时文件与缓存。

在历史列表删除聊天，在模型列表删除已下载的模型。内置模型可能无法单独删除。删除模型不会删除聊天或记忆。

本地删除不会同时清除剪贴板、已分享的副本、其他应用中的内容、设备备份或第三方记录，也不代表存储介质已经过不可恢复的擦除。App 没有自己的聊天云同步；iCloud 和电脑备份遵循系统设置，从旧备份恢复可能带回原有数据。“卸载 App”保留文稿数据，与“删除 App”不同。

本地数据使用 iOS 的应用隔离和权限机制保护。请妥善管理设备解锁、备份与分享；这些机制不能保证所有副本都已加密，也不能消除全部安全风险。

反馈与隐私请求

反馈表单包含您填写的说明、App 版本和 iOS 版本，不会自动附上聊天。通过邮件发送时，我们还会收到您的邮箱地址及自行添加的附件，用于处理和回复。相关信息保留到问题处理和必要跟进结束，之后删除或匿名化；法律要求或争议处理需要保留的部分除外。

如需了解、查阅、复制、更正、补充或删除我们实际处理的个人信息，或提出限制处理、撤回同意等请求，请联系 tangesion@163.com。我们会核实必要信息，按适用法律及时处理；无法满足时，会说明原因和可用的处理途径。请勿发送密码、验证码或无关的聊天内容。

仅存于您设备上的数据，我们无法远程查看或删除，但可以协助您操作。撤回同意后，依赖该同意的后续处理将停止，不影响此前已依法完成的处理。第三方记录可通过其政策渠道申请处理，我们会提供依法需要的协助。本应用没有账户注销步骤。

未成年人

本应用未专门面向儿童设计。未成年人请在监护人指导下使用；处理不满十四周岁未成年人的个人信息，需要依法取得监护人同意并采取相应保护。这份政策本身不代表已取得同意。

如果您或监护人认为相关信息被不当处理，请通过上方邮箱联系，我们会核实并采取必要措施。

政策更新

我们会随功能和数据处理方式的变化更新本政策。涉及处理目的、数据种类、接收方等重要变化时，会提前说明，并在法律要求时重新取得同意；更新不构成对过去处理行为的追溯授权。

本网站的访问

本网站由 GitHub Pages 托管。GitHub 会出于安全目的记录并保存访问者的 IP 地址，无论您是否登录 GitHub。本网站没有自行添加统计脚本或反馈提交表单。详情请参阅 GitHub 隐私声明。
