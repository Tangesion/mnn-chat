哪些功能会联网

模型目录与下载、Agent 搜索和网页读取会请求第三方服务，普通对话仍由本地模型生成。服务方通常能收到 IP 地址、请求时间、网址和请求头，也可能保存请求记录。

模型目录与下载

模型目录来自 meta.alicdn.com，打开或刷新目录即可产生请求。模型文件来自您选择的 ModelScope、Hugging Face 或 Modelers，部分模型信息可能通过 HF Mirror 获取。

这些请求包含模型标识和文件路径，通常不含聊天正文，也可能跳转到平台的存储或分发地址。HF Mirror 是单独的镜像服务，其运营方和规则不等同于 Hugging Face。

ModelScope · Hugging Face 隐私政策 · Modelers · HF Mirror

Agent 搜索

目前依次尝试搜狗（m.sogou.com）、360 搜索（m.so.com）和 Bing（www.bing.com）。结果不足时，同一搜索词会继续发送给后续服务。

搜索词可能包含整段问题，或来自聊天上下文、长期记忆。 搜索服务还会接收连接信息，返回的结果由本地模型继续处理。

搜狗隐私政策 · 360 搜索隐私政策 · Microsoft 隐私声明（含 Bing）

网页、邮件与分享

Agent 会访问您提供或搜索结果中选取的网址，并可能跟随跳转。目标网站会收到网址中的路径和查询参数；其中如果包含个人信息或访问凭据，也会一起发送。

反馈和分享通过您选择的邮件或其他应用发送。反馈默认只带问题描述、App 版本和 iOS 版本；您自己添加的附件也会发送给接收者。

第三方的数据处理

具体保存期限、处理地点和权利申请渠道，请查看对应服务的最新说明。部分平台或网站可能使用境外服务器。本页不代表您已同意第三方的所有处理，也不免除我们依法应履行的义务。相关疑问可发送至 tangesion@163.com。
