Help & support

Start with these answers to common questions.

Common questions

What is a model for?

The model generates answers on your device. You can use an installed model or download another from the model list. Check its size and available storage first; Wi-Fi is recommended for large downloads.

Can I chat offline?

Yes. Ordinary chat works offline with a supported model installed. Catalogs, downloads, Agent searches and webpages need a connection; some screens may still try to refresh the catalog.

Are chats sent to a cloud AI model?

Ordinary chat runs locally. Agent can send search queries based on your question, context or memory to search providers. Feedback and sharing also send the content you choose.

What if generation is slow?

Long conversations, larger models, and thinking mode need more work. Stop the response, start a new chat, or try a smaller model. If the device is hot, let it cool before continuing.

How do I remove local data?

Delete chats in History, and clear memory separately in Settings → Agent Memory and Skills. After clearing memory, stop generation and start a new chat. Downloaded models can be removed in the model list; bundled models may not be individually removable. Shared copies, clipboard contents, backups and third-party records are not cleared by these actions.
