Check important answers

AI can be wrong, outdated or invent information. For health, legal, investment or other important matters, check sources and seek qualified advice when needed. Review generated code and instructions before using them.

When using Agent

Search results, webpages, calculations and memories can all contain errors. Agent uses the internet, and its queries may include your question, context or memory. See the Privacy Policy for details.

Sharing and use
