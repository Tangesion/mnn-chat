使用中遇到问题，可以先看看下面的说明。

常见问题

模型是做什么的？

模型负责在本机生成回答。可以直接使用已安装的模型，也可以从模型列表下载其他模型。下载前请查看大小和剩余空间，大文件建议使用 Wi-Fi。

能离线聊天吗？

可以。已安装的模型支持普通离线聊天。模型目录、下载、Agent 搜索和网页读取需要联网，部分页面也会尝试刷新目录。

聊天会发给云端大模型吗？

普通对话在本机生成。Agent 联网时，可能把您的问题或根据上下文、记忆生成的搜索词发给搜索服务。反馈和分享也会发送您选择的内容。

生成较慢时怎么办？

长对话、大模型和思考模式需要更多计算。可以停止回答、开启新对话或尝试更小的模型。设备发热时可稍后再继续使用。

如何删除本地数据？

聊天在历史列表中删除，记忆在“设置 → Agent 记忆与技能”中另行清除。清除记忆后，请停止生成并新建对话。已下载模型可在模型列表删除，内置模型可能无法单独删除。这些操作不会清理已分享的副本、剪贴板、备份或第三方记录。
